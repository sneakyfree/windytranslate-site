# WindyTranslate.com

The translation engine behind everything. Production-quality website for WindyTranslate — the B2B/developer-focused translation intelligence powering the entire Windy ecosystem.

## Tech Stack

- **Vite** — Fast build tool
- **React** — UI framework
- **Tailwind CSS** — Styling
- **Framer Motion** — Animations
- **Prism.js** — Code syntax highlighting

## Features

- 🎨 Dark mode design with blue/purple technical theme
- 🔍 Interactive model catalog with search and filtering
- 📚 API documentation with code examples (Python, JavaScript, cURL)
- 💳 Pricing tiers with Stripe integration placeholders
- 🏢 White-label and enterprise sections
- 🚀 Quick start guide with copy-to-clipboard functionality
- 📱 Fully responsive design
- ⚡ Optimized for Cloudflare Pages deployment

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

Built for Cloudflare Pages:

1. Connect your GitHub repo to Cloudflare Pages
2. Build command: `npm run build`
3. Output directory: `dist`
4. Deploy!

## Structure

- `/src/components/` — All React components
- `/src/data/` — Mock data for model catalog
- `/public/` — Static assets
- `index.html` — Entry point with SEO meta tags
